## Required comparison procedure

For each component, capture the original and current implementation with the same component width, style, theme, viewport, sample data and comparable animation time. Compare the icon artwork, node/card shape, corner radii, connector routing, typography, spacing, shadows and state changes. Repeat the narrow layout and keyboard interactions. Record specific differences, fix them, then capture a new pair. A build or a screenshot of only one side is insufficient to mark a component visually matched.

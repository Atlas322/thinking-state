# Catalog baseline, batch 3 — 2026-11-09

**Initial-state baseline only; none of these 35 components is marked matched.** This report covers zero-based catalog indices 55–89, Memory Panel through Notification Stack. The parent captured the reference and local browser; this agent analyzed the saved DOM, sampled computed styles, SVGs and accessibility snapshots. No implementation changed for this batch.

All pairs use a 1440×1000 viewport and the captured Clean/light preview, but component widths, preview transforms, animation time, data and expanded state are **not normalized**. Counts and dimensions below describe the captured examples, not intrinsic API limits. Repeated exact scale ratios with unchanged computed sizes suggest preview scaling; that is an inference requiring a controlled recapture.

`metrics` samples representative classes, not every instance. A nonzero box can still belong to visually clipped/popup content; `controls`/`svg` include DOM content that may be closed, hidden or duplicated. Accessibility snapshots help distinguish the visible initial view, but no actions were executed during this analysis. Button's hidden-first sampling issue was resolved by [an all-instance reference capture](live/button-reference-detail.json); the initial sample alone was insufficient.

MIT source bodies must remain intact. Where sampled CSS agrees but example data, icons or supplied callbacks differ, begin with the demo wrapper. No keyboard, hover, click outcome, motion sequence, responsive layout, Classic variant, copy flow or standalone use was certified by this baseline.

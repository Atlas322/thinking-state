# Catalog baseline: first 25 components

2026-11-09. **Baseline only: none of these rows establishes a full review or a match.** This report reads the parent browser's paired public DOM snapshots, representative computed styles, controls and rendered SVG captures in `review/live/catalog`. Captures use a 1440×1000 viewport and Clean/light where available. Sample content, component widths and animation time are not synchronized. Heights of streaming or changing demos therefore cannot be treated as isolated CSS failures.

Each row links its reference and local evidence. “Not present” means absent from the captured view/DOM, not proof that an implementation can never expose it. Controls were inventoried, not exhaustively operated; keyboard, callbacks, error states, responsive layout, both themes/styles and motion sequences remain to be checked. MIT source bodies should stay intact when correcting demo content or wrapper sizing.
